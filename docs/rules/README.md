# Rulebook (not checked in)

`mcr_EN.pdf` is the official Mahjong Competition Rules rulebook, ©2006 World Mahjong
Organization, all rights reserved. This repo is public (see PLAN.md §5), so the PDF itself
is gitignored rather than redistributed — download it yourself from mahjong-europe.org
(MCR section → `mcr_EN.pdf`) into this directory before working on anything scoring/rules
related. Every session and the `rules-lawyer` agent expect it at `docs/rules/mcr_EN.pdf`.

`decisions.md` (checked in) contains short citations and quotes from the rulebook used to
justify specific engine rulings — that's fair-use-style referencing, not redistribution of
the source document.
